数据与备份

GitHub Pages 是静态网页。库存保存在当前浏览器，手机和电脑之间不会自动同步；清除浏览器数据也可能丢失库存。建议每天导出备份。

恢复备份会替换当前设备的数据，请先导出现有数据。

供应商成本说明

旧版已有的供应商报价和采购数据会保留在备份中。库存页面可以设定实际平均成本，供开药成本估算使用。

使用在手机上

上传本文件为 GitHub 仓库根目录的 index.html 并启用 Pages；用手机打开网页后，使用浏览器的「添加到主屏幕」即可像 App 一样进入。
